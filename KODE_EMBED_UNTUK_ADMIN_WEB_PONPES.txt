A. CARA PEMASANGAN DI WEBSITE RESMI PONDOK (HANYA 1 BARIS):
-------------------------------------------------------------------------------------
1. Unggah berkas "chatbot-bahrulmaghfiroh.js" ke folder hosting / public website pondok.
2. Buka berkas template utama website (misal: index.html, footer.php, atau layout.blade.php).
3. Letakkan baris script berikut tepat SEBELUM tag penutup </body>:

   <script src="chatbot-bahrulmaghfiroh.js"></script>

4. Selesai! Ikon chat bulat hijau islami akan otomatis muncul di pojok kanan bawah
   di seluruh halaman website.
