⚡ Integrasi Google Gemini AI (Generative NLP) 🟡 Mode Bawaan Pesantren

Aktifkan Gemini API agar chatbot memiliki kemampuan penalaran kecerdasan buatan (AI) yang super luwes, ramah orang tua santri, dan mampu memahami ragam gaya bahasa penanya.

Cara Mudah Mendapatkan Gemini API Key Gratis (1 Menit):
  1. Buka portal resmi Google AI Studio: aistudio.google.com/app/apikey
  2. Login dengan akun Google/Gmail apa saja.
  3. Klik tombol biru "Create API key", lalu salin kuncinya dan tempel ke kolom di atas. Selesai! (100% Gratis).
